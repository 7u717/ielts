# 雅思

个人雅思词汇应用，沿用 [iue](https://github.com/7u717/iue) 的单色界面系统：纯黑／浅灰双外观、系统 SF / PingFang 字体、细线圆环、悬浮胶囊导航与底部 sheet。iPhone 390px 优先，支持安全区与添加到主屏幕，外观跟随系统且不改写已有设置，无登录、广告和网络字体。

六个话题、144 个精选词条（起步词库，不代表官方完整考纲）。学习引擎基于 [TypeWords](https://github.com/zyronon/TypeWords)，保留打字、听写、错词与 FSRS 间隔复习。

## 使用

右上角主题图标展开竖向圆按钮菜单，再点图标或空白处收回。点首页圆环打开学习概览，轻玻璃浮层只显示两条细进度线，点按进度线才短暂显示数字，点播放图形开始或继续；环下居中的四段图形胶囊切换学习 / 打字 / 听写，第四段打开词表，支持拖动指示。底部图标和左右滑动切换学习、错词、复习。学习页点单词发音、切换释义并唤起键盘，长按松手发音，左滑跳过；输入正确后自动继续。错词列表左滑移出，详情在 sheet 中。左上角头像打开偏好，只显示每日新词刻度和自动发音开关，拖动把手或点背景关闭。每日新词使用小号淡字与细刻度，支持连续拖动、数值轻弹与松手吸附；自动发音整行可点。主题词表默认只显示英文，点词发音并原位展开释义，再点收起，长按查看扩展详情；胶囊第四段列表图形统一打开当前词表。六个主题以紧凑 3×2 竖排小环居中显示，未学为淡完整细环、学过才亮起弧段，主环和小环的零进度以淡细环及微小起点提示，有进度时显示圆头弧段，主环保留缓慢呼吸光晕，点按才短暂显示百分比。学习页右上圆点展开无文字标签的键盘和偏好工具，单词详情使用居中轻玻璃浮层，书签与笔图标分别操作收藏和笔记。学习页左滑跟手，短拖回弹，完整左滑跳过；手势提示沿用原有一次性标记，本组进度以靠近屏幕底部的固定迷你细线随切词更新，同时保留无障碍读数。学习模式不显示光标，字词位于略偏上的视觉中心。打字／听写页使用无框细下划线与光标；字母轻弹、错字轻抖并轻震，正确时短暂完成光晕后自动换词。单词下方详情使用文档图形，顶部工具保留圆点入口。

学习单词按实际字体宽度缩放，长词保持单行与至少 32px 左右留白；释义下方显示一行淡色英文例句，点开详情查看全文。例句优先使用已有词条内容，缺少时使用只读的原创示例，不写入词库或学习记录；打字／听写遮词阶段不显示例句。主题圆点菜单沿用原有开合和错落动画，圆内展示各主题的真实进度弧，浅色遮罩仅轻微模糊变暗。

## 开发与发布

Node.js 24，pnpm 11.25.0。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

默认端口 5567，静态构建：

```sh
NUXT_APP_BASE_URL=/ielts/ ORIGIN=https://7u717.github.io pnpm generate
```

输出 `.output/public`。推送到 `master` 后 Actions 构建、部署并验证线上 HTML 与 PWA manifest：

https://7u717.github.io/ielts/

## 记录与兼容

沿用已有 IndexedDB / localStorage 键和版本，不重置词典进度、错词、FSRS、统计或笔记。不同主题、打字 / 听写 / 复习任务使用新增的 `ielts-session:*` 归档键；旧模式 `0` 和旧缓存仍兼容。首次手势提示仅新增 `ielts-gesture-hint-v1`。原备份逻辑保留，包含原导出内容及新增的任务归档；本次仅隐藏其界面入口。

记录只在此浏览器/域名内保存；iOS 主屏幕应用与 Safari 的存储可能分开。网页缓存不清理 IndexedDB，也不承诺首次使用即可完整离线。发音优先使用 HTTPS 有道英式音频，失败回退 en-GB 系统语音。首次用户交互同步解锁同一个音频元素和系统语音；回到前台后等待下一次手势重新解锁。系统语音能否离线发音取决于设备已安装的声音。

## 移动回归检查

用独立浏览器上下文测试，不读取真实用户记录。

```sh
npm install --prefix /tmp/ielts-browser playwright
PLAYWRIGHT_MODULE=/tmp/ielts-browser/node_modules/playwright \
  node scripts/verify-mobile.cjs
```

设置 `CHROMIUM_BIN` 指定浏览器（默认 `/usr/bin/chromium`），`IELTS_TEST_URL` 指定开发或静态站点地址，`IELTS_SCREENSHOTS` 指定截图目录。检查导航/拖动、sheet、原生 input 事件、自动学习与 FSRS、旧记录恢复、模式归档、错词移除和精简偏好。

`node scripts/verify-pronunciation.mjs` 检查手势限制、媒体失败回退和取消竞态。`scripts/verify-preferences-audio.cjs` 使用真实 Chromium 媒体播放和本地 WAV 网络夹具，验证点击、长按、自动发音、偏好及旧记录，并输出 390px 截图。`scripts/verify-sheet-polish.cjs` 检查词表点按/长按、原位详情、连续刻度拖动及吸附、整行开关并输出 390px 截图。`scripts/verify-study-polish.cjs` 检查首页轻量进度、词表把手、学习页亮度/布局、一次性提示、左拖跟手与回弹。`scripts/verify-detail-grid.cjs` 检查六主题网格、词表展开、工具菜单、居中详情、收藏/笔记持久化及回弹关闭。`scripts/verify-materials.cjs` 检查深浅两种 390px 外观、零／有进度圆环、概览、胶囊拖动、玻璃面板和阻尼关闭，并验证切换系统外观不写入学习记录。`scripts/verify-input-polish.cjs` 检查深浅 390px 打字／听写、完整居中小环、图形概览、输入光标、错字触感、完成光晕和自动换词，并保存截图。`scripts/verify-precision.cjs` 检查四段胶囊的屏幕中心、起点柔光、紧凑概览、学习无光标、字词／进度线布局及偏好数值动效，保存深浅两套完整截图。`node scripts/verify-examples.mjs` 检查 144 个词条的示例覆盖及数据只读；`scripts/verify-light-glass.cjs` 检查深浅 390px 轻玻璃浮层、点线显示数字、主题实际进度弧、长词留白、例句详情与底部固定进度，并保存六类页面截图。以上测试不能确认有道服务当时的可用性，也不能替代 iPhone 真机音频检查。
